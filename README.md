# Zeeman-simulation
In this repository has been proposed a simulator of the normal Zeeman effect and the usual Zeeman effect with the purpose of the characterization of the quantum physics that makes this effect possible and the comparison with experimental values.

En español 
Desarrollo en Python de un simulador del desdoblamiento Zeeman normal y anómalo en sistemas atómicos sencillos. Implementación de factores de Landé, reglas de selección dipolares, generación de espectros sintéticos y diagonalización matricial del Hamiltoniano con acoplamiento espín-órbita. Visualización de diagramas E(B) y comparación cualitativa con datos espectroscópicos de referencia.
